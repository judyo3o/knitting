# 도안 단수 카운터

뜨개 도안(PDF·사진·텍스트)을 올리면 **파트별(스와치·뒷판·앞판·몸통·소매·카라…) 탭**으로 나누고, 지금 뜨는 단을 **차트 위에 분홍 띠로 표시**하고, 그 아래에 서술 도안을 **묶음 단위 버튼**으로 보여주는 뜨개 진행 앱이에요. 배색 도안은 **색을 표시**하고 **배색 격자를 직접 그릴 수** 있어요.

- 진행(단 완료 시각, 작업 세션, 묶음 진행)은 **이 기기 안(IndexedDB)** 에만 저장돼요. 10분마다 백업 스냅샷도 남아요.
- 홈 화면에 설치하는 앱(PWA)이라 **오프라인에서도** 돼요. AI는 도안 읽기와 "차트를 글로 풀기"에만 써요.
- 원본 PDF는 기기에만 저장되고, AI로 보내는 건 고른 페이지뿐이에요.

## 기기에서 먼저, 못 하는 것만 내 Claude로

앱 하나로 돌아가요. 서버가 없고, 이 기기에서 할 수 있는 건 전부 기기에서 해요.

| 기기에서 (무료·오프라인) | 내 Claude로 (토큰 사용) |
|---|---|
| 단 세기·완료 시각·기록, 차트 위 현재 단 표시, 기호표, 서술 묶음 진행·콧수 추정 | 사진·스캔 PDF 도안 읽기 |
| 글자가 있는 PDF·텍스트 도안 읽기 (사이즈별 숫자 고르기, 차트 쪽, 게이지·스와치) | '1단과 동일', 'Rep 2nd round' 같은 다른 단 참조가 있는 도안 |
| 배색 그리기·이미지에서 배색 만들기·게이지 계산 | '이 단 차트를 글로 풀기' |

기기에서 일부만 읽혔으면 "기기에서 읽은 대로 시작"과 "Claude로 정확하게" 중에 고를 수 있어요.

⚙ 설정에서 Claude 연결을 골라요.
- **내 Claude API 키**: console.anthropic.com에서 만든 키. 이 기기 안에만 저장되고 Anthropic API로만 바로 보내져요. 쓴 만큼 요금이 나가요. (Claude Pro/Max 구독 로그인 토큰은 다른 앱에서 쓸 수 없어서 API 키가 필요해요.)
- **키 없이**: 앱이 고른 페이지만 잘라낸 PDF와 프롬프트를 만들어 주면, claude.ai 새 채팅에 넣고 받은 답(JSON)을 붙여넣어요.

같은 페이지를 다시 읽을 때는 저장된 결과를 써서 토큰을 아껴요.

## 주요 기능

- **올리기**: PDF(썸네일에서 페이지 선택, `2, 5, 7-12` 범위 입력, 서술 페이지 자동 선택 — 한국어·영어, 대바늘·코바늘), 사진 여러 장, 텍스트 붙여넣기, 배색 차트 "빈 차트로 시작 / 이미지로 시작"
- **파트 탭**: 파트마다 현재 단을 따로 기억. 마지막 단에서 "이 파트 완료 ✓", 그다음 "다음 파트로 →"
- **현재 단 카드**: 겉면 RS/안면 WS · 진행 방향 · 단 번호 · 콧수 · 이 단의 색
- **차트 표시**: PDF 텍스트 레이어의 단 번호 축으로 단 위치를 찾아 현재 단 주변만 크게, 분홍 띠 + 진행 방향 화살표, 이미 뜬 단은 회색. 확대/축소, 차트 전체, 원통뜨기, 기호표(자동으로 찾아 왼쪽에)
- **서술 묶음**: 묶음을 누르면 그 자리까지 저장, "8/23 묶음 · 왼바늘에서 약 54코 뜸"
- **차트를 글로 풀기**: 현재 단 띠와 기호표를 AI에 보내 서술로 쓰고, 한 번 더 점검
- **배색**: 도안의 색 기호(A, MC, C1…)와 색 이름을 칩으로 표시, PDF 차트 띠에서 실제 색 추출
- **배색 그리기**: 선택·색칠·채우기·지우개, 복사/붙이기, 좌우·상하 반전, 가로·세로 반복, 반복 단위 표시, 단/코 추가·삭제, 되돌리기. 설정에서 게이지(칸을 실제 코 비율로), 칸 그리기(격자/코 모양), 색 경계선, 범례(색별 코 수), 굵은 선 간격, 코 번호 방향, 픽셀 보기 PNG. 단마다 "A 3코, B 1코 …" 서술이 자동으로 생기고(RS는 오른쪽부터, WS는 왼쪽부터), 긴 플로트(6코 이상)를 알려줘요
- **이미지로 시작**: 이미지 바꾸기, 자르기 상자(모서리·변 끌기), 가로 콧수·세로 단수(게이지 비율 유지), 보기 3가지(원본 / 원본+격자 / 격자 결과), 색 수 자동 추출(2~8색)과 색 고치기·추가
- **게이지**: 무늬마다 도안 게이지 · 세탁 전 · 세탁 후(10cm 안 콧수·단수). 도안과의 차이(%)와 바늘 조정 안내, 세탁 후 변화, 도안 콧수·단수 → 내 게이지 환산. PDF의 게이지 문구는 자동으로 채우고, 10cm가 아닌 크기("42코 30단 / 19×13cm")는 10cm로 바꿔요
- **기록**: 단 완료 시각, 30분 단위 작업 세션, 진행 기록 목록, 내보내기/가져오기(JSON), 백업에서 복원
- 화면 켜두기, 키보드 → / ← / 스페이스

## 직접 실행하기

```bash
npm install
```

```bash
npm run dev
```

브라우저에서 http://localhost:5173 을 열어요.

## 배포

정적 앱이라 아무 정적 호스팅에 올리면 돼요. **GitHub Pages**: 저장소 Settings → Pages → Source를 "GitHub Actions"로 두고 `main`에 올리면 `.github/workflows/pages.yml`이 빌드해서 배포해요. 휴대폰·컴퓨터에서 열고 "홈 화면에 추가"(설치)하면 앱처럼 써요.

## 개발

```bash
npm test
```

```bash
npm run typecheck
```

```bash
npm run e2e
```

```bash
npm run check -- fixtures/내도안.pdf 2,23,24,25,26,27
```

```bash
node scripts/analyze.mjs fixtures/내도안.pdf L
```

```bash
node scripts/real-e2e.mjs fixtures/내도안.pdf:L
```

- `npm test`: 순수 로직 단위 테스트 (파서, 묶음 콧수, 페이지 자동 선택, 차트 축 감지, 기호표, 배색 격자)
- `npm run e2e`: Playwright로 앱 전체 흐름 (합성 테스트 PDF를 만들어 씀)
- `npm run check`: **차트 정렬 점검** PNG를 `check-out/`에 만들어요. 인자 없이 실행하면 합성 PDF로, PDF 경로와 쪽을 주면 그 도안으로 만들어요. `check-out/index.html`에서 띠가 양옆 단 번호와 같은 높이인지 확인해요.
- `scripts/analyze.mjs`: 실제 도안으로 자동 페이지 선택·기기 읽기·차트 축·기호표·게이지 결과를 출력
- `scripts/real-e2e.mjs`: 실제 도안을 앱 화면에서 올리고 파트·차트 띠·Claude 요청(잘라낸 PDF)까지 확인

도안 PDF는 저작물이라 저장소에 올리지 마세요. `.gitignore`가 `*.pdf`와 `fixtures/`를 막아요.

구조와 설계는 [PLAN.md](PLAN.md), AI 도우미용 안내는 [AGENTS.md](AGENTS.md)에 있어요.
